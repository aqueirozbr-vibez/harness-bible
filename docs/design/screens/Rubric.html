Evidence rubric v1.2 · published 01 Jul 2026 · next review Q4 2026 · changes are curator-only and announced

The adjudicator grades each evidence item by tier, then adjusts it for relevance, recency and independence. The suggestion's score is set by its strongest item. A curator decides what the rubric cannot.

Evidence tiers·A–G, Ubase score before adjustment
tiernameexamplesbase
A Reproducible A saved lab run in the IDE that reproduces the claimed change. A derive script diff. A runnable notebook with data. 100
B Primary published Peer-reviewed paper. Preprint with code. Standard or regulation text. Official specification. Audited filing. 85
C Primary vendor Official documentation, pricing page, changelog, release note or model card from the vendor concerned. 70

G Opinion Social media post. Forum comment. Unsourced blog. Personal assertion. 5
U Unverifiable Link cannot be opened. Document not supplied. Claim without artefact. Graded as unverifiable, not as weak. 0
scoring rule · stated once

The strongest item decides. Ten weak items never equal one strong one.

score = max( base × relevance × recency × independence )
      + 10 once, if a second independent item is tier D or above

Never a sum. Never an average. Corroboration adds 10 at most.
