# Harness Bible Interactive — UI and style guide

- style-guide.html — the complete style guide (open in a browser; follows system light/dark).
- screens/ — every screen as a standalone HTML page (open any file; hb.css beside them). 18 screens.
- png/ — the same screens rendered at frame size (desktop 1440 wide, mobile 390 wide).

The product and technical requirements documents (`PRD — Harness Bible Interactive.pdf`, `TRD — Harness Bible Interactive.pdf`) are internal documents for now and are not part of this package.
