rationale v0.9.0 · PRD 2026-09-21 · hb.css v0.9.0 · release 2026.09 · sha 7f3a9c1e

The product is built on its own harness, so the interface shows the harness. Every screen names its version, its sources and its verdicts. A reader should trust a number exactly as far as its evidence goes, and no further.
