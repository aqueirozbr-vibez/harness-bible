Why does Lab 21 still need idempotency keys if Temporal retries activities? Does Temporal Cloud bill for replayed events?

assistant · 10:42cites en v1.5.0

Retries and keys solve different problems. A retry cannot tell whether the failed attempt already reached the external system 21.2.

Temporal's default retry starts at 1 s with a backoff coefficient of 2.0. A retried write without a key is a second write 21.3.

In the P-101 scenario that is 117 duplicate side effects a day without durable execution, and 0 with it 21.3 Lab 21 · README.

Billing for replayed events: the book does not cover this. To measure your own billing lines, see 15.4.
