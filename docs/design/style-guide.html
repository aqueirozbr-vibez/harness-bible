The style guide

Harness Bible Interactive turns a 41-chapter engineering reference into a book you can navigate, an assistant that answers only from it, an IDE for its labs and a wiki that improves on graded evidence. The interface is a lab bench. Every panel is a labelled, versioned instrument; every number says where it came from; every state is written in form as well as colour. Nothing here decorates. If an element does not carry information, it is removed.

ProvenanceThe reference site typesafe.ai was consulted for sensibility — mono metadata, thin rules, restraint. Its exact tokens could not be sampled from the fetched page, so every value below is a chosen default per the brief, recorded in hb.css v0.9.0.

§ 01 · principles

Five rules that decide every other rule

  1. ✢

    Every panel is an instrument.

    A panel has a label, a version and a timestamp before it has content. If you cannot name what it measures, it is not a panel.

  2. ✢

    Numbers carry provenance.

    Every figure carries a source-tier chip, a derive link or an illustrative mark. A bare number is a defect, not a style choice.

  3. ✢

    State in form, not only colour.

    Verified, stale and failed differ in shape, line and word as well as hue. The interface reads correctly in greyscale and in print.

  4. ✢

    Parity is a layout constraint.

    Portuguese and English ship together. Every label is sized for the longer edition; nothing truncates; figures are identical in both.

  5. ✢

    The harness is visible.

    Versions, hashes, budgets, rubric scores and run logs are shown, not hidden behind a friendly surface. The reader is an engineer.

scoring rule

Score = the strongest item's adjusted score, plus 10 once for a second independent item at D or better. Never a sum. Adjustments multiply: relevance 1.0 / 0.6 / 0.2; recency, fast-moving only, ≤ 90 d 1.0 / ≤ 1 y 0.7 / older 0.3; independence none 1.0 / vendor concerned 0.8 / contributor's employer 0.7.

§ 11 · voice

Voice

Write like the book: short declarative sentences, specifics over adjectives, British spelling. The reader is an engineer checking a claim.

  • ✢ No exclamation marks. No "seamless", "powerful", "unlock", "supercharge".
  • ✢ British spelling: organisation, colour, licence, behaviour, analyse, optimise.
  • ✢ Buttons are verbs that describe the result: Run, Save run, Attach as evidence, Submit for grading.
  • ✢ Errors say what failed, what was kept and what to do next.
  • ✢ A number replaces an adjective whenever one exists.
